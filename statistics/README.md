# 統計ラボ
高校数学と発展学習のための、ブラウザ内で動く統計実験アプリです。`index.html` を直接開くか、リポジトリルートから `python -m http.server 8000` を実行して `/statistics/` を開きます。ビルド・外部ライブラリ・外部通信はありません。

## 学習テーマ
- 二項分布：n と p、理論分布、標本の相対度数、成功回数の裾確率。
- 正規分布：μ と σ、区間確率、z 値、±1〜3σ、区間境界のドラッグ。
- 仮説検定：正確二項検定。片側・両側、有意水準、棄却域、帰無仮説下の実験。両側は確率順序法。
- 信頼区間：正規母集団の平均に対する z 区間（σ既知）/ t 区間（σ未知）。標本抽出と区間の被覆を反復。母比率の区間は未対応。
- χ二乗検定：2×2 / 2×3 のクロス集計。Pearson独立性検定（補正なし）、期待度数、各セルの寄与、χ²分布。期待度数5未満は注意表示。
- t検定：1標本、対応あり（差 A−B）、独立2標本のWelch。片側・両側検定と、両側95%信頼区間（固定）を併記。

## 操作
「1ステップ」で生成・計算・記録の3段階を進みます。「再生」はこの過程を連続実行し、速さ変更・一時停止ができます。二項分布・正規分布・仮説検定・信頼区間は1/10/100回実験を追加できます。χ二乗検定・t検定は固定データの計算過程を説明するため、実験の反復ボタンは「説明を一巡」に変わります。

シードと「最初から」で同じ乱数列を再現できます。条件を編集すると記録はリセットされます。記録は最新3000実験まで保持し、信頼区間の図は最新28区間を表示します。「動きを減らす」は再生の更新間隔を長くします。OSの動きを減らす設定を初期値に反映します。

t検定は数値を空白・改行・カンマで貼り付けられます（各標本2〜1000個）。対応ありでは順序と個数を一致させてください。各画面で計算方法・前提条件を確認できます。個人情報を含まない例題データの利用を想定しています。

## 計算と検証
`stats.js` に計算を分離。正規CDFは不完全ガンマ関数、t分布CDFは不完全ベータ関数、分位点は二分法です。p値が0.0001未満なら数値の丸めによる0表示を避けるため `< 0.0001` と表示します。

`node statistics/stats.test.js` で二項・正規・t・χ²の既知値、検定、乱数再現性、区間の被覆を検証します。近似分布や検定には前提があり、このアプリは教育用です。
