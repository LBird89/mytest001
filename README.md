# かたちラボ
数学の授業向けの、数式を3次元で観察するアプリです。HTML / CSS / JavaScript のみで動き、外部ライブラリ・通信・ビルドは不要です。

## 使い方
`index.html` をブラウザで開き、基本版 v1 / 斜回転対応版 v2 を選んでください。ローカルサーバーを使う場合は、このディレクトリで `python -m http.server 8000` を実行します。

- **回転体**: `y=f(x)`、x の範囲、x 軸または y 軸を指定。再生・一時停止、角度の直接指定、速度変更ができます。回転による側面を描きます（端面は省略）。
- **曲面**: `z=f(x,y)` と x / y の範囲を指定。
- **曲線**: `x(t), y(t), z(t)` と t の範囲を指定。
- 数式・範囲は入力後に自動更新し、回転軸は選択時にすぐ反映します。編集時は回転角度を維持します。不正な入力では最後の有効な描画を残し、エラーを表示します。
- ドラッグで視点を回転、ホイールで拡大縮小。PNG 保存にも対応。

`sin, cos, tan, sqrt, abs, exp, log, ln, asin, acos, atan`、定数 `pi, e`、演算 `+ - * / ^` が使えます。角度はラジアンです。掛け算は `2*x` と明示してください。`^` はべき乗で、`-x^2` は `-(x^2)` と解釈します。

数式は専用パーサーで解釈し、JavaScript として実行しません。範囲に非有限な値が含まれる場合は入力エラーを表示します。有限個の標本を線や面で結ぶ描画なので、特異点・不連続点・非常に細かい振動の厳密な表示には適しません。

## 検証
`node --test math.test.js` で式の解釈と入力拒否を確認できます。

## 斜回転（直線を軸にした回転）
回転軸メニューから「直線 y = ax + b のまわり」を選び、傾き a と切片 b を指定します。数式（例: `1/2`、`sqrt(2)`）も使えます。各値は −10000〜10000 に制限しています。

「斜回転：放物線と y=x」は `y=x^2, 0≦x≦1` を `y=x` のまわりに回す例です。「切片のある軸」では `y=x+1` を使います。

補助表示では、橙色が回転軸、P が元の点、H が垂線の足、P′ が回転後の点、破線の円が一周の軌跡です。点のスライダーで観察位置を変更できます。表示するのは曲線の回転でできる曲面であり、領域の回転による体積の計算や端面の表示は行いません。

`rotation.js` が垂線の足と軸周りの回転を計算します。`node rotation.test.js` で既知の斜回転、切片のある軸、半径の保存、描画範囲を検証できます。

## バージョン別の公開
- `/` : バージョン選択ページ
- `/v1/` : GitHub main の従来版（e30a3f7 時点）。タイトルの版表示とトップへの戻り先以外、アプリのコードは維持しています。
- `/v2/` : 斜回転対応版

GitHub Pages は `main` / `/ (root)` から公開します。この変更を main にマージすると、同じサイトで両方を利用できます。各フォルダ内の HTML / JS / CSS は相対パスで読み込み、外部ライブラリやビルドは不要です。ローカルでファイルを直接開く場合、各版は `v1/index.html` または `v2/index.html` を開いてください。

数式テスト: `node math.test.js`、回転の幾何テスト: `node rotation.test.js`。テストは v2 の実装を対象とします。
